## Claude Code only
- **Desktop app:** `.claude/launch.json` runs the app for the Browser pane: `app` with the fakes, `app-real` with the chat on the real model, which spends neurons (`AGENTS.md`, Boundaries), both on port 3000, and `app-build` with the fakes on port 3200. After a UI change, check the page there once before you finish: with `app-build` in a build-lane worktree, with `app` otherwise (`docs/plan.md`, Now, the lanes). Never `app-real` outside the measurement lane. `preview_start` runs `app-build` in the folder the session started in: in a worktree entered later, it served the main checkout’s code (found 2026-10-20). Check the server’s folder, or start `npm run dev -- --port 3200` from the worktree and open its address with `preview_start`’s `url`. A session that started in the main checkout and made its worktree afterwards gets `app-build` started in the main checkout, on its code (its log lists `.env.development.local`, which a worktree hasn't got): run `npm run dev -- --port 3200` in the background from the worktree instead, open `http://localhost:3200` with `preview_start`'s `url`, and stop the server afterwards (found 2026-10-20). Stopping that background command can leave Next's own server process listening on 3200: check the port, and end that process too. That `next dev` also writes its block into `AGENTS.md` (KI-8): undo it before you commit.
- **Worktree sessions** (desktop worktree option or `claude --worktree`): run `npm ci` first. `.worktreeinclude` copies `.env.local` in for you, not `.env.development.local`, so `npm run dev:real` works in the main checkout only, unless the owner copies that file in by hand. A worktree made with `git worktree add` and entered afterwards gets no copy: run `npm run env:local` with the local stack up, or the chat refuses every request for want of `AI_PROVIDER` (found 2026-10-20, as 24 failed end-to-end tests).
