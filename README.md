# PRD Assistant

PRD Assistant is a web app being built to turn research notes into a product requirements document (PRD) in which every statement cites the passage it comes from, with each citation checked by the app's own code.

## Status

- **Planning:** done. The product description and the scope are approved.
- **Build:** in progress.
- **Demo:** none yet.

## Documents

- [Product description](docs/product/prd.md): the product requirements document for the first version.
- [Scope](docs/product/mvp.md): what the first version includes and what it leaves out.
