## Design
- 2026-10-17 · Desktop first; on a phone the chat and the PRD stack on one page, usable not polished; the home page opens on a short intro screen, then shows the chat with the PRD beside it; quotes open their source in a pop-over, with the researcher's question above the answer; no separate UX document · The PRD's Design section is the design brief
- 2026-10-17 · The demo explains itself through progressive disclosure: the intro screen makes the visitor the product manager, with the researcher's six interviews as finished records, and its one button drafts the first section; the AI drafts before asking and asks only what the transcripts don't say, explaining once that the answer becomes the visitor's own decision; each step shows as one line that opens its passages; quotes show their source by name and the check's result, explained once next to the first section; a suggestion to try to break it appears only after the first section, with a claim nothing in the interviews comes close to (grocery delivery), while the dark mode claim, which Henk's words come close to, stays in the quality check as the harder test; a quiet link leads engineers to the README and the code · Replaces the opening summary, the upfront gap questions and the suggested first messages; the quality check tests the new flow
- 2026-10-17 · Black and white colour scheme: black dominant (main backgrounds and large surfaces), white in support (text, lines, accents). Not allowed: cream or off-white backgrounds, italic accent words in headlines, numbered "01/02/03" section labels, monospace labels, pill-shaped buttons · Feeds the PRD's Design Considerations and every UI piece

## Data
- 2026-10-17 · `saveSection` takes a drafted section as a list of statements, each with its citations, checks it and stores it, and the visitor confirms it before the next section; a citation quotes an interview passage (checked against the interviewee's answer, never the researcher's question) or the visitor's own chat message (checked against what they wrote, never the assistant's messages); the code flags statements that cite neither; a quote passes when it has the same words in the same order, ignoring case, spacing, quote style and punctuation at the ends; contradictions show both views with citations and the choice goes under Open Questions; a statement with no citation fails the quality check, except in the Open Questions section; the quality check counts as passed only after two passing runs in a row; on failure, fix the prompt or try a stronger model on the same free tier, never loosen the check · Defines the citation check and the quality check
- 2026-10-17 · The citation check proves the quoted words exist and belong to that person, not that the statement reads them fairly · Every quote sits next to its statement, and the README says so plainly
- 2026-10-17 · The database holds only the sample-note passages with their embeddings (six short interviews, so tens of passages) and the rate-limit counts by hashed IP; no files or images; the agent drafts the fictional interviews and the owner reviews them · No file storage; the load script is the only way notes get in
- 2026-10-17 · Sample notes: six fictional interviews by a researcher about a shared household grocery list app, approved by the owner, in `notes/`; finished records that the AI quotes and never asks again; deliberate gap: offline use in a store with bad signal; deliberate contradiction: a notification for every added item is wanted by some and a reason to uninstall for others · Drives the quality check
- 2026-10-17 · The PRD lives in the visitor's browser and survives a reload; a "Start over" button clears it and returns to the intro screen; sections change only through the chat · Every change to the PRD goes through the citation check

## Access
- 2026-10-17 · Visitors are anonymous: no sign-in, no roles, no admin screen; the owner works only through staging, the quality check and the hosting settings; English only, no currency · No sign-in or translation setup in stage 3
- 2026-10-17 · When the free quota runs out, the chat input is hidden and the message links to the README's screen recording and the repository · Replaces the plain friendly message
- 2026-10-17 · Rate limit: 30 messages per visitor per day, recognised by hashed IP address kept only for the limit window; kept after the free limits were checked: the per-minute limit and the monthly budget are the tighter caps · Needs a legal basis the owner chooses (see Money and legal)

## External services
- 2026-10-17 · Every AI key comes from an account or project with no billing attached, so running out of quota fails instead of charging · No spending limit to manage; quota exhaustion is the expected failure
- 2026-10-17 · AI provider: Mistral in Free mode for both chat and embeddings, through `@ai-sdk/mistral`; the Mistral API runs in EU data centres by default (https://docs.mistral.ai/resources/known-limitations.md) · One package and one account; the quota message reacts to error 402, which Mistral returns once the free monthly usage is used up and pay-as-you-go is off (https://docs.mistral.ai/resources/error-glossary.md). Replaces the paid-key plan in the brief; Gemini's free tier is ruled out for EEA users (https://ai.google.dev/gemini-api/terms)
- 2026-10-17 · No Labs models (API names starting `labs-`), because they don't allow opting out of data collection; Mistral's training setting stays off, and the app never sends feedback to Mistral · Mistral doesn't train on the app's API data (owner's reading of the terms; https://docs.mistral.ai/inference/model-lifecycle.md)
- 2026-10-17 · Models, by Mistral's pinned API names: chat `mistral-small-2603` (Mistral Small 4), not the `-latest` alias, which can change without notice; stronger fallback if the quality check fails: `mistral-large-2512` (Mistral Large, December 2025; Free mode offers Medium only as `mistral-medium-latest`, an alias); embeddings `mistral-embed-2312` (Mistral Embed), 1024 dimensions (https://docs.mistral.ai/models.md, https://docs.mistral.ai/inference/model-lifecycle.md) · The vector column is 1024 wide and the fake embedder returns 1024 numbers; changing the embedding model means embedding all notes again; any model change reruns the quality check
- 2026-10-17 · Mistral Free mode, checked by the owner while logged in: a US$10 budget a month for API and Studio use, reset on the 1st (Vibe Code has its own); per-minute token limits of 20,000 for the small chat model, 250,000 for the large one and 20,000,000 for embeddings, each at about 1 request a second; the training setting is off · Chat is the bottleneck, so the app must tell visitors when the demo is busy (error 429) apart from the quota being used up (402); the quality check paces its requests; tokens per full PRD and the official prices (https://mistral.ai/pricing) give how many PRDs the budget covers
- 2026-10-17 · No payments, email, background jobs or file storage in the first release, so none of the `.kit/modules/` apply · Stage 3 sets up only the AI provider

## Money and legal

- 2026-10-17 · Owner's reading of Mistral's Commercial Terms (https://legal.mistral.ai/terms/commercial-terms-of-service, effective 25 Sep 2026; not legal advice): they govern API use (Mistral's EU consumer terms exclude the API), allow offering your own product to end users, and contain no clause limiting Free mode to private or test use · The public demo can run on Free mode
